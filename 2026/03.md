ブラウザがコードをどのように解釈してユーザーインターフェース（UI）を作成（またはレンダリング）するのか

ユーザーがウェブページにアクセスすると、サーバーはブラウザにHTMLファイルを返します。
ブラウザはHTMLを読み込み、ドキュメントオブジェクトモデル（DOM）を構築する。
DOMはHTML要素のオブジェクト表現です。コードとユーザーインターフェースをつなぐ役割を果たし、親子関係を持つツリー状の構造をしています。

DOMメソッドとJavaScriptを使用して、ユーザーイベントをリッスンし、DOMを操作できます。ユーザーインターフェース内の特定の要素を選択、追加、更新、削除することで、DOM操作を行うことができます。DOM操作では、特定の要素を対象とするだけでなく、そのスタイルやコンテンツを変更することも可能です。

JavaScriptを使用してUIを更新する
JavaScriptとDOMメソッドを利用してページを構築
Scriptタグ内ではscript、DOM メソッドを使用できます

HTMLが初期ページコンテンツを表すのに対し、DOMはあなたが書いたJavaScriptコードによって変更された更新後のページコンテンツを表すため

命令型プログラミングは、シェフにピザの作り方を手順ごとに指示するようなものです。宣言型プログラミングは、ピザを作る手順を気にせずにピザを注文するようなものです。🍕

宣言型プログラミングがReact


<html>
  <body>
    <div id="app"></div>
    <script type="text/javascript">
      // Select the div element with 'app' id
      const app = document.getElementById('app');
 
      // Create a new H1 element
      const header = document.createElement('h1');
 
      // Create a new text node for the H1 element
      const text = 'Develop. Preview. Ship.';
      const headerContent = document.createTextNode(text);
 
      // Append the text to the H1 element
      header.appendChild(headerContent);
 
      // Place the H1 element inside the div
      app.appendChild(header);
    </script>
  </body>
</html>
