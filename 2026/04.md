## React 学習 初週の振り返り

### やったこと
https://nextjs.org/learn/react-foundations/updating-state
公式Chapter７まで学習
- React 学習の全体計画を確認
- React の基本的な使い方と JSX 記法を学習
- コンポーネントの設計原則を理解
- Props によるデータ受け渡しを学習
- useState Hook を使った状態管理を体験

### 新たに得た学び
- React がなぜ生まれたのか、その背景を理解できた
  - JavaScript での DOM 操作の複雑さが、React の必要性を生んだ
- JSX 記法の便利さと、コンポーネント思考の重要性を実感
  - 再利用可能なコンポーネントを作成する楽しさ
- Props と State の違いを理解できた
  - Props: 親から子へのデータ受け渡し
  - State: コンポーネント内部の状態管理
